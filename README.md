# VendorHub — Wedding Vendor Marketplace

**Internship task:** WD-MAT-005  
**Student code:** DAS-MAT-005  
**Domain:** Wedding Vendor Marketplace  
**Company listed in task brief:** Data Alcott Systems

VendorHub is a responsive front-end demo that helps couples discover wedding service providers, browse vendor details, save favourites and create local booking requests.

## Features
- Home page with search and wedding-themed hero section
- Vendor categories: venues, photographers, caterers, florists, makeup artists and planners
- Vendor cards with sample location, rating, starting price and portfolio image
- Search and filters by category, budget and rating
- Vendor detail modal with services and sample packages
- Booking request form and “My Bookings” list
- Favourites / wishlist
- Dashboard summary cards
- Dark mode and responsive mobile navigation
- Browser `localStorage` for demo persistence

## Technologies
- HTML5
- CSS3
- Vanilla JavaScript
- Browser localStorage

## Run locally
1. Download and extract the ZIP.
2. Open `index.html` in a modern browser.
3. Internet access is recommended for remote Unsplash images and Google Fonts. The basic app functionality runs locally.

No database or build tools are required. The project is a front-end prototype; bookings are not sent to real vendors, and login/payment are not connected to a backend.

## Files
- `index.html` — page structure and dialogs
- `style.css` — layout, colour theme and responsive styles
- `script.js` — sample data, filters, favourites, bookings and dashboard
- `README.md` — project information and setup notes

## Important note
All vendor profiles, ratings and prices are fictional sample data for demonstration. Replace them with verified, permissioned information before any real-world use.
